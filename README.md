Audio Convertor (used ffmpeg)


Support all audio formats: m4a, aac, mp3, flac, wav, ogg, wma, opus, aiff, ape, mp2, ac3...

Shows the actual source format: M4A, FLAC, OGG и т.д.

Output format: mp3, flac, ogg, wav (Dropdown list).

The bitrate is always for MP3 flac and wav - without bitrate (lossless), mp3 and ogg - with the bitrate from the original.
